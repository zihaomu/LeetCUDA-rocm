# shared-KV / shared-QKV rr：B2 验收记录

更新时间：2026-11-05。状态：B2 两个入口功能验收完成，正式支持175/229（76.42%）；性能待优化。

## 实现与契约

新增 `flash_attn_mma_stages_split_q_shared_kv_acc_f32_rr` 与
`flash_attn_mma_stages_split_q_shared_qkv_acc_f32_rr`。FP16 Q/K/V/P/O，QK、PV、online max/sum 和整个输出状态均为 FP32；没有更改累加精度。

支持 D=32/64/96/128/256；KV 的 D256 只支持 stage1，其余均支持 stage1/2。
保持原 stage 别名：<=1→1、>1→2。连续尾部、空形状、未对齐连续视图、设备 guard 与当前 stream 均独立验证。

D>64 时，同一 CTA 中两组 warp 共同搬运 Q/K/V，各自负责约一半输出列，减少每线程活跃输出状态。P 只有第一组写入；QK 仍在两组重复计算。D<=64 不拆分。KV 保留 Q 的 LDS；QKV 将 Q 缓存在寄存器后复用其 LDS。D256 的 query tile 为64；QKV D256/stage2 的 key tile 为32，满足64KiB LDS。

## 资源和性能

主卡为物理GPU5（PCI a3，HIP7）；第二卡物理GPU2（PCI43，HIP1）用于正确性。避开预约GPU4/6及禁用GPU3。性能新旧实现同卡交替测量，8次调用/graph、每组40ms、5组样本、3轮。

| 配置 | 父实现→rr资源变化 |
| --- | --- |
| KV D256/stage1 | VGPR243→155，均无spill |
| QKV D128/stage2 | VGPR256→183，spill12→0 |
| QKV D256/stage1 | spill127→13，仍有scratch |
| QKV D256/stage2 | 29个spill；父实现没有相同stage2契约 |

| 入口 | 同契约配置数 | 三轮父实现/rr几何平均 | 最坏退化 |
| --- | ---: | --- | ---: |
| KV rr | 11 | 0.96237 / 0.96202 / 0.96247 | 33.52% |
| QKV rr | 11 | 0.99566 / 0.99581 / 0.99547 | 19.50% |

D256/stage1 相对父实现约1.09×（KV）/1.33×（QKV）；D128变慢，原因包括重复QK和更多wave的同步/调度成本。QKV D256/stage2另有3条记录，只与父stage1作信息性比较，未混入同契约统计。功能支持与性能优化分别记录；不能宣称全形状加速或全部无spill。

首版独立CTA分片会重复全局搬运，且实验中原主卡出现其他任务，原始结果保留在[首版研究](flash_rr_20261105/initial_independent_cta/hip.json)，不用于最终独占性能结论。
